# 5\. Gemini APIキーの取得手順（Google AI Studio）

対象：管理者
種別：初期設定

Google AI Studioにアクセスし、「Get API key」から本システムでAIを動かすためのAPIキーを発行し、管理者がシステムに登録します。

## 内容

①Google AI Studioを開きます。
Google AI Studio：https://aistudio.google.com/prompts/new\_chat

<br>
②左下にある「鍵マーク」を押します。
※Get API Keyをいう名前に準拠するボタン

<br>
③Get API Keyページが開きます。

<br>
④右上にある、「APIキーを作成」を押します。

<br>
⑤名前は分かりやすいものに設定します。
※例：「記帳AI用」
⑥プロジェクトを作成します。
※既に今般のツール用のプロジェクトがあればそれを使用
⑦プロジェクトの名前を設定します。
例：「Gemini API」

<br>
⑧Gemini API キーが発行されます。

<br>
⑨右の方にある「コピー」マークをクリックしてコピーします。

<br>
⑩コピーしたAPIキーは設定で使います。メモ帳などに保管しておくとスムーズです。
※社内限定のchatなどに、保管しても問題ありません。
